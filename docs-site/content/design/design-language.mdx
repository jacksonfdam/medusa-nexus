# MEDUSA NEXUS — Visual Design Language

Extracted and adapted from the local reference project `CyberpunkHackersToolkit`. Pure cyberpunk hacker terminal — black canvas, neon cyan, acid green, magenta, Courier Prime monospace, CRT scanlines, glitch overlays.

This document is authoritative for every UI decision: Pencil screens, future React components, report HTML themes.

---

## 2. Typography

- **Primary family:** Courier Prime (Regular, Bold, Italic, Bold Italic). Monospace terminal font. Used for 99% of the UI.
- **Display family (rare):** Rye — decorative titles only.

### Scale

| Style | Size | Weight | Line height | Letter spacing | Usage |
|---|---|---|---|---|---|
| Display Large | 57 | Regular | 64 | -0.25 | Hero titles |
| Display Medium | 40 | Regular | 48 | 0 | Section titles |
| Display Small | 32 | Regular | 40 | 0 | Subtitles |
| Body Large | 16 | Regular | 24 | +0.5 | Main content |
| Body Large Header | 16 | Bold | 24 | +2 | Section headers (`KALI::TOOLKIT` style) |
| Body Medium | 14 | Regular | 20 | 0 | Dense tables, commands |
| Label Small | 11 | Regular | 16 | +0.5 | Status labels, timestamps |
| ASCII Letter | 72 | Regular | 72 | -4 | Single-letter section anchors |

### Copy voice

Short, acid, command-line flavored:

- Primary buttons: `[EXEC]`, `[RUN]`, `[KILL]`, `[PULL]`, `[BYPASS]`, `[SAVE]`, `[VALIDATE]`, `[LOAD]`.
- Status badges: `● CONNECTED`, `● OFFLINE`, `● SCANNING`, `● IDLE`.
- Empty states: `SIGNAL LOST`, `NO PROJECTS — GO FIND SOMETHING TO BREAK`, `ENGINE OFFLINE`, `NO CAPTURES YET`.
- Footer: pulsing `_ SYSTEM READY _`.

## 3. Motion & effects

| Effect | Implementation | Duration | Trigger |
|---|---|---|---|
| **Glitch** | Magenta/green channel displacement ±3px | 2000 ms infinite | Always-on (hero elements) |
| **CRT flicker** | Random XY shake ±1px | 32 ms interval | Always-on |
| **Scanlines** | Horizontal 2dp lines moving down, Multiply blend | 8000 ms infinite | Overlay on content area |
| **Neon glow** | Box/text-shadow, soft cyan | Static | Interactive + hero elements. 8dp default, 20dp hero. |
| **Chaos text** | Horizontal slice + random scale/color overlay | 500 ms burst | Auto every 2–3s or on tap |
| **CRT box scanline overlay** | 2dp black lines, 4dp gap, Multiply | Static | Panel overlay |
| **Pulse opacity** | 1.0 ↔ 0.5 | 500 ms cycle | Footer status |
| **Arrow rotation (expand)** | 0° → 90° tween | 300 ms | Expand/collapse |
| **Expand transition** | Fade + slide-in vertical | 150–300 ms | Expand/collapse |

**Easing:** Linear for scanlines and flicker; standard tween for UI state changes.

## 4. Layout patterns

### 4.1 Screen skeleton

```
┌─────────────────────────────────────┐
│  HEADER (fixed)                     │   ← brand + clock + status badges
├─────────────────────────────────────┤
│  CRT BOX — main title               │
├─────────────────────────────────────┤
│  CRT BOX — tagline / chaos text     │
├─────────────────────────────────────┤
│  MAIN CONTENT (scrollable)          │
│   ├─ [A] ASCII HEADER               │
│   │   ├─ Row 1 [EXEC]               │
│   │   └─ Row 2 [EXEC]               │
│   ├─ [B] ASCII HEADER               │
│   │   └─ Row 3 [EXEC]               │
├─────────────────────────────────────┤
│  FOOTER (fixed, pulsing)            │
└─────────────────────────────────────┘
```

### 4.2 Spacing

- Vertical gap between sections: **32dp**.
- Vertical gap between rows: **12dp**.
- Horizontal padding (main): **16dp**.
- Header/footer padding: **12dp**.
- Content padding: **24dp** vertical, **16dp** horizontal.

### 4.3 Section headers (ASCII anchors)

Single large letter (A, B, C, …) at **72dp** with `letter-spacing: -4`. Glitch applied. Underline: linear gradient `primary/cyan → secondary/magenta → transparent`. Optional layered color overlays: magenta @ 50% + acid @ 30%.

## 5. Base components

All components use: 1dp border, 2dp radius, monospace typography.

- **Panel / Card** — `bg/panel` background, `border/default`, cyan glow on hover.
- **Button (primary / secondary / destructive)** — labels in brackets (`[EXEC]`, `[KILL]`). Hover bumps background and border opacity.
- **Status badge** — bullet + uppercase label. Accent color by state.
- **Severity chip** — color by severity token, uppercase text (`CRIT`, `HIGH`, `MED`, `LOW`, `INFO`).
- **Tab bar** — terminal style, `> overview` for active, `  static` for inactive.
- **Input** — terminal prompt with blinking cursor, dark semi-transparent background.
- **ASCII section header** — described above.
- **Data row** — chevron + name (grows) + status badge/label on the right. Chevron rotates on expand.
- **Hex divider** — horizontal `[::][::][::][:]` line in `muted/cyan`.
- **Risk gauge** — circular arc 0–100, fill color transitions by severity.
- **Graph node / edge** — attack surface nodes, cyan border, severity-colored fill when a finding lands on them.
- **Finding card** — header (title + severity chip + engine tag) · Evidence (mono snippet, syntax-highlighted) · **Mitigation** (highlighted with accent border, always visible, not collapsible by default).

## 6. Iconography & motifs

- Chevron (Material `KeyboardArrowRight`) for expand/collapse.
- Bullet `●` for status.
- Bracket markers `[EXEC]`, `[OPEN]`, `[RUN]`, `[KILL]`.
- ASCII patterns `[::][::][::][:]` for dividers.
- Large single-letter anchors for section navigation.
- Gradient underlines under ASCII anchors.
- Continuous scanline overlay at 5% opacity on content areas.

---

## 7. Implementation notes for the Pencil deck

- Set all text styles to Courier Prime (fall back to any monospace if unavailable).
- Apply 1px cyan borders at 30% opacity on every panel.
- Use 2px radius globally (no rounded corners).
- Neon glow = drop shadow, blur 8, cyan @ 60%.
- Scanline overlay = repeating-linear-gradient pattern (2px solid / 4px transparent).
- Component variants follow the states: `default`, `hover`, `active`, `disabled`.
- Animations that cannot be expressed inside Pencil (CRT flicker, scanline motion, chaos text) are annotated with a text block in the frame describing the intended runtime behavior.
